brainana — non-human-primate MRI preprocessing pipeline

USAGE
  Docker:
    docker run --rm --gpus all \
      -v <bids_dir>:/input -v <output_dir>:/output \
      -v <work_dir>:/output_wd -v <license.txt>:/fs_license.txt \
      liuxingyu987/brainana:<version> [bids_dir] [output_dir] \
        [--freesurfer_license PATH] [--config PATH | --config_file PATH] \
        [-w PATH | --work_dir PATH] [--no_resume] \
        [--subjects SUBJECT[,SUBJECT...]] [--sessions SESSION[,SESSION...]] \
        [--tasks TASK[,TASK...]] [--runs RUN[,RUN...]] \
        [--anat_only] [--output_space SPACE] [-profile PROFILE] [-h | --help]

  Local (from source):
    ./run_brainana.sh run main.nf --bids_dir PATH --output_dir PATH [OPTIONS]

  Interactive shell (Docker):
    docker run -it ... liuxingyu987/brainana:<version> bash

POSITIONAL ARGUMENTS (Docker)
  bids_dir                     BIDS root directory mounted into the container. Default: /input
  output_dir                   Output directory mounted into the container.   Default: /output
                               (Locally, pass these as --bids_dir / --output_dir instead.)

GENERAL OPTIONS
  --freesurfer_license PATH    FreeSurfer license file inside the container (required when
                               surface reconstruction is enabled), e.g. /fs_license.txt.
                               Default: (none)
  --config PATH,               Custom YAML config file inside the container (optional; built-in
  --config_file PATH           defaults are used when omitted). Default: (built-in)
  -w PATH, --work_dir PATH     Nextflow work directory. Mount a host dir here to persist it
                               across runs and enable resume. Default: <output_dir>_wd
  --no_resume                  Disable Nextflow resume; restart the pipeline from scratch.
  -h, --help                   Show this help and exit.

BIDS FILTERING OPTIONS
  --subjects SUBJECT[,...]     Restrict to the listed subject IDs, comma-separated
                               (e.g. 01,02; omit the "sub-" prefix).
                               Default: (all subjects)
  --sessions SESSION[,...]     Restrict to session IDs, comma-separated (omit "ses-").
                               Default: (all sessions)
  --tasks TASK[,...]           Restrict to task names, comma-separated (functional only).
                               Default: (all tasks)
  --runs RUN[,...]             Restrict to run indices, comma-separated. Default: (all runs)

PROCESSING OPTIONS
  --anat_only                  Run only the anatomical pipeline; skip functional. Default: False
  --output_space SPACE         Template space for registered outputs. Either a bundled template
                               spec TEMPLATE_NAME[:DESCRIPTION] (e.g. NMT2Sym:res-1 [1 mm],
                               NMT2Sym:res-05 [0.5 mm], MEBRAINS:res-05), OR a path to a CUSTOM
                               template file (.nii/.nii.gz). Default: NMT2Sym:res-05
                               NOTE: custom templates use --output_space <file>. There is no
                               --custom-template flag.

RESOURCE OPTIONS
  -profile PROFILE             Nextflow resource profile: minimal (4 CPUs, 16 GB) |
                               recommended (8 CPUs, 32 GB). Default: built-in (8 CPUs, 20 GB)
  NXF_MAX_CPUS=N   (env var)   Max CPUs for Nextflow, e.g. docker run -e NXF_MAX_CPUS=8 ...
  NXF_MAX_MEMORY=SIZE (env)    Max memory for Nextflow, e.g. docker run -e NXF_MAX_MEMORY=20g ...

FLAG CONNECTORS
  Underscore is canonical (e.g. --work_dir, --no_resume, --freesurfer_license). The hyphenated
  spellings (--work-dir, --no-resume, --freesurfer-license, --output-space, ...) are accepted
  as aliases and normalized automatically.
