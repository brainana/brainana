brainana design system

One palette, type scale, and component set for every brainana surface. This page links the canonical brainana-tokens.css in this folder; each surface applies the same token values (see DESIGN_SYSTEM.md for how).

The standard way: keep a small set of semantic tokens — named by role (surface / text / line / brand / status), not by hue. You theme these ~10; everything else derives from them. Yellow (--bn-accent) is decorative only — heading underlines, rails, hover tints — never text and never a state signal. Run status uses a three-tier palette — green pass, amber pass-with-warnings, red fail — so tolerated task failures never read as a clean success.

Typography — IBM Plex Sans + Plex Mono

Heading — Plex Sans 600
Body — IBM Plex Sans, 16px, line-height 1.5 (GitHub rhythm). The quick brown fox jumps over the lazy dog.
Code & values use Plex Mono: WORKING_DIR, NMT2Sym, sub-032309m.
